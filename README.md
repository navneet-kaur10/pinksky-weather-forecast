# PinkSky Weather – Weather Forecast Website

About the Project:
PinkSky Weather is a weather website built using HTML, CSS, and JavaScript. It allows users to search for any city and check its current weather and 5-day forecast.
The website uses the Open-Meteo API to get weather information and display it in a simple and user-friendly design.

Features:
- Search for weather by city name.
- Display current temperature and feels-like temperature.
- Show humidity, wind speed, visibility, and air pressure.
- Display a 5-day weather forecast.
- Show sunrise and sunset times.
- Display current date and time.
- Show weather icons and descriptions.
- Handle empty searches and invalid city names.
- Responsive design for different screen sizes.

Technologies Used:
- HTML – Used to create the structure of the website.
- CSS – Used for design, colours, animations, and layout.
- JavaScript – Used to make the website interactive.
- Open-Meteo API – Used to get weather information.
- Fetch API – Used to request weather data.
- JSON – Used to read the data received from the API.

How It Works:
1. The user enters a city name.
2. JavaScript sends the city name to the Geocoding API.
3. The API returns the city's location coordinates.
4. These coordinates are used to get weather information.
5. JavaScript displays the weather details on the website.

2. Open the project folder.

4. Search for a city to check its weather.
